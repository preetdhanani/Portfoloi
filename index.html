Local LLM Training & Optimization Suite

On-premise SFT and DPO alignment

A training platform that runs supervised fine-tuning and DPO on 7B and 8B models, Llama 3 included, on one 16 GB GPU. Datasets, logs and checkpoints never leave the machine.

Each job runs in its own subprocess, so the OS gets all CUDA memory back when it ends. Preference data follows a strict prompt, chosen and rejected schema, and a React dashboard streams loss and GPU metrics live.

60%less GPU memory

Production RAG Platform

Hybrid retrieval, reranking and live evaluation

BM25 keyword search and FAISS vector search run side by side, then a cross-encoder reranks the merged results. Query expansion helps with vague questions and prompt compression keeps the context small.

An ingestion pipeline turns PDFs, Markdown, HTML and crawled docs into one index. MLflow tracks retrieval scores, latency and answer faithfulness against reference queries.

Deck Engine

Schema-constrained LLM generation, v1.0.0

Turns a short brief into an on-brand, editable PowerPoint. Layouts, chart types and template cloning are decided in code. The model only writes text and data.

Every field is checked three times: in the prompt, as a JSON schema and again after generation. If the model has nothing true to say it leaves the field empty. Failed items retry with the exact error and go to a human after repeated failure. Anthropic, Gemini and local Ollama sit behind one interface.
